# Política de Privacidad — Laundry Manager

**Última actualización:** Mayo 2026  
**Desarrollador:** Videcreaciones

## 1. Información que recopilamos

Laundry Manager **no recopila ningún dato personal** del usuario.

Toda la información que el usuario ingresa en la aplicación (nombres de prendas, propietarios, fotos, notas y categorías) se almacena **únicamente en el dispositivo local** del usuario mediante la librería Hive. Esta información nunca es transmitida a servidores externos ni compartida con terceros.

## 2. Fotos

Las fotos tomadas o seleccionadas desde la galería se almacenan localmente en el dispositivo. La aplicación no sube ninguna imagen a internet ni a servicios de almacenamiento en la nube.

## 3. Permisos utilizados

La aplicación solicita los siguientes permisos:

- **CAMERA:** Para tomar fotos de las prendas. Solo se activa cuando el usuario lo solicita explícitamente.
- **READ_MEDIA_IMAGES:** Para seleccionar fotos desde la galería del dispositivo.
- **INTERNET:** Únicamente para verificar si hay actualizaciones disponibles en GitHub. No se transmiten datos del usuario.
- **POST_NOTIFICATIONS:** Para enviar recordatorios locales de lavado. Las notificaciones se generan en el dispositivo y no pasan por ningún servidor externo.

## 4. Datos de terceros

La aplicación no integra servicios de analítica, publicidad, rastreo ni ningún SDK de terceros que recopile información del usuario.

## 5. Actualizaciones

La función de actualización automática consulta únicamente la API pública de GitHub para comparar la versión instalada con la última versión disponible. Esta consulta no incluye ningún dato personal ni identificador del usuario o del dispositivo.

## 6. Menores de edad

Laundry Manager no está dirigida a menores de 13 años y no recopila intencionalmente información de menores.

## 7. Eliminación de datos

Dado que todos los datos se almacenan localmente, el usuario puede eliminar toda su información en cualquier momento desinstalando la aplicación.

## 8. Cambios a esta política

Cualquier cambio en esta política de privacidad será publicado en este mismo documento con una nueva fecha de actualización.
